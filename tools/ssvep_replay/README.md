# SSVEP 修正后的真人验收

仅使用 O1、O2、P3、P4，FBCCA；不添加 OZ，不训练或接入个人模型。

## 已修正的时序

- 分类滤波为连续 257 点 FIR（6–45 / 14–45 Hz），不再对每个窗口截掉 256 点。
- 250 Hz 下，滤波启动等待 256 点，即 1.024 秒；随后使用完整 625 点（2.5 秒）做 CCA。
- 第二个一致窗口最早约在刺激开始后 3.776 秒产生，还需等待实际数据包抵达。
- 游戏与操作训练最长刺激 6 秒；游戏额外保留 0.5 秒结果接收余量。接收余量不允许使用刺激截止后的样本。
- 丢失样本保留在时间轴上；窗口不会跨数据缺口或显示时序中断，重置后重新等待滤波稳定。
- 开销：四导联、两滤波组只对新样本滤波；250 Hz 时新增滤波缓冲约 160 KB，按一次采集样本只处理一次。
- 分模式拒识配置仍以 0.52 / 0.08 / 两个一致窗口为保守初值，标记为未验证。分数占比不是正确概率。

## 为什么暂不降低门槛

现有两个明确单目标注视记录不足以验证四/六目标。离线回放发现部分前置静息窗口也通过单窗口分数门槛，降低门槛可能扩大误选。2.5/3/4 秒回放结果保存于 `.smoke-user-data/fbcca-repair-replay/comparison.md`；其中没有模拟线上重叠窗口投票，窗口相符比例不能当作独立试次准确率。

## 补录顺序

1. 在采集软件核对导联名称、O1/O2/P3/P4 接触、参考与地电极、阻抗和量程是否符合设备说明。软件不能仅凭直流偏移判定接触或响应正常。
2. 保持同一次采集，睁眼静息 20 秒。
3. 原理演示：12 / 15 Hz 单目标分别注视 10 秒，交替各 3 次，试次间停止并休息 10 秒。必须逐次开始/停止，记录实际注视目标；选择目标只表示提示，不自动确认实际注视。
4. 刺激时序诊断：12 / 15 Hz 纯色单目标各测试 3 次，注视对应块，试次间休息。当前持续 6 秒；采集开启时会自动保存纯色刺激起止标记，可与扑克牌记录比较。比较时取相同分析时长，避免把两种刺激不等长的整段 RMS 直接相减。
5. 四/六目标原始频率组合需各目标有明确注视的重复试次与同频率配置的静息对照。现有教学最多四目标；六目标先在游戏中记录自己实际注视的牌与试次顺序。原始游戏规则答案可自动记录，但不能替代实际注视标注。
6. 简单、进阶、困难分别完成至少 10 次选择，记录正确、错误、拒识、反应时间和重试；不同尝试可能属于同一手牌，应按试次和手牌分别统计。
7. 按独立试次划分验证集；确定门槛时同时检查静息误选率和注视正确率，不用重叠窗口充当独立试次。只在未参与门槛选择的试次上报告验证结果。

```powershell

node tools/ssvep_replay/evaluate.mjs .smoke-user-data/replay
```

标注文件以 trialId 为键，例如：

```json
{"实际trialId":{"attentionConfirmed":true,"source":"逐次人工记录"}}
```

只能对实际确认的注视试次标记 true；无注视顺序的双目标记录不能补填成六次单目标测试。

## 刺激形式对照

历史 v1–v3 的牌面/纯色对照采用以下方案；新的「开始注视对照」使用文末的中央六条件方案。

- 先睁眼静息 20 秒；随后 12/15 Hz × 扑克牌/纯色块 × 3 次重复。
- 每次提示目标 2 秒，预检刷新率，然后刺激 6 秒；试次间休息 10 秒。
- 两种形式使用同一画布、相同目标位置和外框尺寸、相同亮度调制参数；保存实际响应式尺寸，分析时核对。
- 不使用分类器提前停止，也不接入个人模型；测试过程中导航锁定，停止、隐藏窗口或采集结束会取消对照。
- 采集标记只记录提示，`attentionConfirmed=false`；完成后由本人确认实际注视，漏看试次不能补为已注视。
- 这是两种整体呈现形式的比较，还改变了静止牌面、中心图案和空间平均亮度，不能单独归因为闪烁面积。
- v3-fixation 为纯色块加入与牌面一致的固定明暗同心注视点，静止和刺激时均显示；保存 `fixationPoint` 标记。历史 v2 无点记录不修改，两版本应分开比较。

导出并比较：

```powershell
python tools/ssvep_replay/prepare.py --session '会话目录' --out '.smoke-user-data/stimulus-comparison' --annotations '实际注视标注.json'
python tools/ssvep_replay/compare_stimuli.py .smoke-user-data/stimulus-comparison
```

使用每次刺激后的 1.25–5.25 秒，共 4 秒数据；一致的 2–45 Hz 显示带通和 Hann PSD，比较基波/二次谐波局部 SNR、频带 RMS 和前置静息。分析排除过短、丢帧、中断和平直导联试次；逐对检查尺寸位置及注视确认。频带 RMS 包含背景脑电，不等于纯诱发幅度，也不使用统一「正常幅度」界限。

## 历史轮次：中央静态 / 12 Hz / 15 Hz 诱发筛查

以下保留历史 `central-solid-evocation-v1` 的分析方案，不将其与当前六条件试次混合。

- 协议 `central-solid-evocation-v1`；单个中央纯色块，固定明暗同心注视点；所有条件同位置、尺寸、平均数字亮度，12/15 Hz 起始相位均为 0，调制幅度 0.45，静态幅度为 0。
- 睁眼静息 30 秒；5 个独立组，每组静态、12 Hz、15 Hz 顺序打乱，各 10 秒；准备 2 秒、预检刷新率约 1 秒，组内外休息均 10 秒。总共 15 次，约 6 分钟。
- 静态记录同样从实际首帧开始计时并保存起止标记，`activeTargetIds=[]`、频率 0。静态仍执行 RAF 以记录时序，像素不闪烁。
- 保存条件、重复组、实际顺序、几何、调制参数、起止数据到达年龄和首帧回调延迟。数据到达停滞、标记保存失败、严重丢帧、窗口隐藏/缩放或采集停止时中止；不自动重试或补为有效试次。
- 数据年龄限值为 `max(100 ms, 1.5 × 包时长)`，用于发现传输停滞；它不是设备到屏幕的绝对延迟。同步仍为网关到达估计，`hardwareSynchronized=false`。已有服务无需重启，原始采样轴与旧标记不更改。
- 每次按提示持续注视中央点；漏看、转头或中断应记下试次序号。软件不自动确认实际注视。

导出后运行：

```powershell
python tools/ssvep_replay/prepare.py --session '会话目录' --out '.smoke-user-data/evocation-next' --annotations '实际注视标注.json'
python -m tools.ssvep_replay.analyze_evocation .smoke-user-data/evocation-next
```

预先固定 O1/O2 平均功率为主要区域，仍逐导联保留 O1/O2/P3/P4 指标。取 1.5–9.5 秒的 8 秒窗、2–45 Hz 带通、Hann PSD，比较 12/24/15/30 Hz：

1. 局部 SNR：目标频点 PSD 与 ±0.5、±0.75、±1 Hz 六个频点的平均 PSD 比值，以 dB 表示。
2. 诱发条件相对同组静态条件的目标 PSD 变化，以 dB 表示。对独立组作单侧配对标签交换检验，并对四个预设频点作 Holm 校正；不把重叠窗或四个电极当作独立重复。
3. 所有条件同时计算四频点，检查增强是否跟随 12/15 Hz 条件切换。

5 对的最小精确单侧 p 为 1/32，四项 Holm 校正下无法达到 0.05：本轮是筛查，不能据“未显著”断定没有响应。有线索后需增加独立重复。当前未实现硬件同步的相位推断或谱 F/Hotelling T² 检验；Hann 邻频不直接视为独立样本。未确认注视的结果始终标记为探索性。

不加入 Oz、不拟合个人模型、不调整游戏频率、刺激时长或拒识门槛。

## 历史轮次：中央外围闪烁扑克牌 / 纯色块六条件与前后比较

入口：「设备与实验 → 刺激时序诊断 → 开始注视对照」。准备后由本人点击开始，软件不代替本人确认注视。

- 协议 `central-appearance-comparison-v1`。扑克牌、纯色块各有静态、12 Hz、15 Hz，共六种条件。
- 8 个完整随机组，每组包含所有六种条件，共 48 次。每次 10 秒，准备 2 秒并预检刷新率，普通试次间休息 10 秒；开始前睁眼静息 30 秒。
- 第 24 次后暂停，休息至少 90 秒，再由本人点击「继续第二段」；不会自动继续。两段各包含四个完整随机组，总计约 21 分钟，额外休息会增加时间。
- 所有条件为同一中央位置、外框、固定明暗同心注视点；牌面固定 7♣、相位 0。数字基线 0.5，闪烁幅度 0.45，静态幅度 0。数字参数一致不代表显示器物理亮度或实际调制面积一致。
- 每次保存真实首帧、起止样本位置、时序统计、形式、条件、随机组、执行段、实际顺序与预设分析窗。中断、数据停滞、尺寸改变、严重丢帧或标记失败会停止，不补为有效试次。
- 记录漏看、头部明显移动或其他异常的试次序号；完成后用实际注视标注导出。未确认的分析保留探索性标记。

```powershell
python tools/ssvep_replay/prepare.py --session '会话目录' --out '.smoke-user-data/appearance-next' --annotations '实际注视标注.json'
python -m tools.ssvep_replay.analyze_appearance .smoke-user-data/appearance-next
```

采集前固定分析方法：先对整次试次连续进行 2–45 Hz 滤波，再切窗，切段处不重置滤波器。

|分析窗|相对真实首帧时间|长度|
|---|---|---|
|主分析 full|1.5–9.5 秒|8 秒|
|早段 early|1.5–5.5 秒|4 秒|
|晚段 late|5.5–9.5 秒|4 秒|

- O1/O2 平均**功率**为预先固定主要区域，保留四导联的 PSD、局部 SNR、带内 RMS。六个频点 12/24/36/15/30/45 Hz 在所有条件下均计算；36/45 Hz 仅作描述，45 Hz 位于滤波截止处。
- 主要比较完整 8 秒的「牌面相对自身静态增强 − 纯色相对自身静态增强」，12/24/15/30 Hz 四项双侧配对标签交换检验，Holm 校正。正值为牌面更强，负值为纯色更强。
- 前后比较同一试次的「晚段 − 早段」，并扣除同组同形式静态的对应时间变化。两种形式 × 四分量共八项双侧检验，作为独立的次要校正家族。前后两窗不当成两个独立重复，完整窗也不增加样本量。
- 同组缺少条件、重复条件、形状尺寸或牌面不一致时，相关配对排除；逐次输出排除原因和实际组数。未完成两段时不会补齐 48 次。
- 8 组的最小双侧 p 为 2/256，四项主要检验可以达到校正后 0.05，但八项次要检验的最小 Holm p 为 0.0625，无法达到 0.05。前后结果用于描述方向与重复性，未显著不能证明前后完全相同。
- 输出 `appearance-analysis.md`、JSON 和逐试次逐导联三窗 CSV，单位 μV²/Hz、μV、dB。同长早晚窗可以比较；不直接将 4 秒与 8 秒 SNR 差异解释成生理变化。

同步仍是网关数据包到达估计，不声称硬件同步、神经来源已证实或游戏正确率已测得；本轮不修改游戏识别参数。

## 历史轮次：整牌闪烁，无外围闪烁

入口不变：「设备与实验 → 刺激时序诊断 → 开始注视对照」。协议为 `central-cardface-comparison-v1`，与原外围闪烁数据分开。

- 两种形式：`card-face` 整张牌面明暗调制，`solid` 同牌面尺寸的均匀纯色块。两者均以牌面矩形为实际调制范围，圆角 10 px；外围与阴影保持静止，中央明暗同心点保持固定。
- 牌面按瞬时 RGB 灰度乘以缓存像素：以裁剪的黑色覆盖层实现，透明度 `1 − level/255`。纯色块使用同一 `level`，沿用映射 `round(42 + 178 × luminance)`。在数字基线 0.5、幅度 0.45 时，白色牌面区域和纯色块使用约 51～211 的 RGB 灰度。
- 每帧复用明亮牌面缓存，避免在上次已变暗的图上重复叠加；先绘制牌面、再调制、最后重绘固定标记点。无 CSS 滤镜、新动画库或整屏逐像素运算。
- 静态条件同样为该形式的中等亮度，幅度 0；保持静态、12 Hz、15 Hz × 两形式 × 八组，共 48 次，两段各 24 次，段间休息至少 90 秒后手动继续。
- 整体尺寸、位置、起始相位、正弦波、10 秒时长、2–45 Hz 分析带通与完整/早/晚窗口均沿用已固定方案；正式游戏刺激与识别参数未改动。
- 标记额外保存 `stimulusFootprint=card`、`outerFlicker=false`、`brightnessMethod`、实际 `modulatedRegionGeometry`、RGB 映射。相同几何和数字参数不等于物理亮度完全相同，牌面仍存在不同空间图案。

```powershell
python tools/ssvep_replay/prepare.py --session '会话目录' --out '.smoke-user-data/cardface-next' --protocol central-cardface-comparison-v1 --annotations '实际注视标注.json'
python -m tools.ssvep_replay.analyze_appearance .smoke-user-data/cardface-next --protocol central-cardface-comparison-v1
python -m tools.ssvep_replay.summarize_appearance .smoke-user-data/cardface-next
```

可用 `--run-id` 与 `--segment 1/2` 限定导出已完成的单阶段。新协议分析核对调制范围、外围关闭和渲染方法；原外围协议不混入本轮的八组主要检验，若比较历史数据必须单独说明尺寸和呈现方式变化。

## 历史轮次：三形式统一随机对照

入口仍为「设备与实验 → 刺激时序诊断 → 开始注视对照」。新协议 `central-three-form-comparison-v1`，不拼接历史试次。

三种形式：

1. `card` 原外围闪烁：原尺寸外围明暗调制，牌面保持静止；保留原 RGB 蓝通道 +5 的呈现。
2. `card-face` 整牌闪烁：仅牌面明暗调制，外围静止。
3. `solid` 纯色块：与整牌同尺寸、同圆角的均匀调制块，外围静止。

所有形式均为同一中央位置、固定标记点，牌面 7♣、起始相位 0，保持原正弦波、数字基线 0.5、幅度 0.45。

- 每种形式各有静态、12 Hz、15 Hz，九种条件，每个随机组包含全部九种，八组共 72 次。
- 两段各 36 次，均为四个完整随机组。开始静息 30 秒、每次 10 秒、普通间隔休息 10 秒，加上准备与刷新率预检，总计约 30 分钟；段间至少休息 90 秒，手动继续。
- 静态对照按各形式独立保存，中断不自动补齐。保存真实序号、组号、执行段、起止标记、画布尺寸、实际调制范围、静止遮挡范围、RGB 通道样式和亮度方法。
- 外围与整牌/纯色的实际调制范围、空间图案及平均物理亮度不同；外围保留原呈现细节。本实验比较三种整体呈现，不将差异单独归因于刺激面积。
- 分析分别比较整牌−外围、整牌−纯色、外围−纯色，均先扣除同组自身静态。四个预设频点 12/24/15/30 Hz × 三对，共 12 项双侧检验，统一 Holm 校正，不将三对拆开以降低校正力度。
- 同次试次早晚比较为三形式 × 四个频点，单独 12 项校正家族。仍先连续滤波整次，再切完整 1.5–9.5 秒、早 1.5–5.5 秒、晚 5.5–9.5 秒窗口；不把半窗当独立试次。
- 八组时最小双侧 p=2/256，12 项 Holm 最小 p=0.09375，不能达到 0.05。本轮用于描述方向、大小和重复性，不能把未显著解释为三种效果相同或没有诱发。

## 当前轮次：短版形式与注视点筛选

入口不变：「设备与实验 → 刺激时序诊断 → 开始注视对照」。页面须显示「短版」「共 30 次」；仍打开旧桌面构建的窗口需要刷新或重新打开以载入当前版本。协议 `central-short-fixation-comparison-v1`，历史数据不拼接。

- 三种形式（原外围、整牌无外围、同牌面尺寸纯色块）各有固定点、同步点，共六种组合。
- 同步点使用目标同一亮度计算值、频率和相位，明暗同心圆 RGB 同乘 `level/255`，不使用独立动画计时器。外围版本的牌面仍静止，只有外围和中央小标记点同步；正式游戏默认点不变。
- 六种组合各做 **一次**十秒静态参考；固定点与同步点中等亮度不同，故保留各自参考，取消每组重复静态。
- 六种组合 × 12/15 Hz × 两次重复，24 次主动闪烁。静态六次与主动24次合计 **30 次**，约11分钟。每个主动随机组包含所有12种条件。
- 先睁眼静息20秒；每次10秒、准备2秒并预检刷新率、间隔休息6秒。第18次（六静态+第一主动组）后至少休息60秒，手动继续第二主动组12次。
- 保留完整1.5–9.5秒、早1.5–5.5秒、晚5.5–9.5秒；整次连续2–45Hz滤波后切窗。显示丢帧、标记错误、尺寸改变和持续断流仍停止。
- 包到达允许 `max(500 ms, 3×每包采样时长)` 的短暂延迟；当前400ms包对应1200ms。保存策略版本，分析使用同一阈值；不会把中断试次补为有效。
- 分析分别输出邻频SNR、相对自身静态增强、三组形式两两比较、同步−固定点比较以及同次前后变化，基频和谐波均保留四导联指标。
- **只作初步筛选**：每主动条件只有两次，静态参考一次，被两次主动试次共享，不增加独立重复数。不给显著性或稳定诱发结论；同时保留原始主动功率差，以免静态背景改变被误认为诱发增强。
