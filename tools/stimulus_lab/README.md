# 刺激形式与算法实验工作台

此文档是 `codex/stimulus-form-debug` 首版实验协议及复现说明。基线为 main 提交 `e1ceefd6a0d52ad5d00b7e1f68c5155db6f31025`，协议版本 `multi-target-form-algorithm-v1`。

## 启动与边界

```powershell
npm ci
python -m pip install numpy scipy
npm start
```

默认进入实验工作台，隐藏游戏、教学入口与启动动画。原模块保留；开发检查可使用页面查询参数 `?app=original`。本分支分析在源码运行环境执行，需要可用的 Python、NumPy、SciPy 和 Node.js；旧版安装包不包含这套离线分析环境。可用 `BRAIN_GAME_ANALYSIS_PYTHON` 指定分析 Python 路径。

连接厂商采集软件的数据服务，点击连接网关、开始采集。正式实验固定使用 **P3、P4、Oz、Pz**；任一缺失均禁止开始。原始值按厂商输出的 μV 保存，不额外缩放。通道“数据正常”仅表示该导联存在且数据包新鲜，不代表电极阻抗或信号质量合格。

新建实验后保存随机种子和实际计划。预览设置只影响预览；正式批次始终执行保存的计划，不由预览选择改变协议。点击开始下一批后，先检查 60 Hz 刷新率，再记录本采集会话一次 20 秒睁眼静息。

启动默认最大化窗口。刺激画布必须全部位于可见屏幕内；若窗口过小或滚动使部分刺激不可见，将阻止开始或停止当前试次。不要在刺激期间滚动、缩放或移动窗口到其他缩放比例的屏幕。

## 固定刺激配置

| 数量 | 频率（Hz） | 布局 |
| --- | --- | --- |
| 2 | 12、15 | 左右 |
| 4 | 7.5、8.57、10、12 | 两行两列 |
| 6 | 7.5、8.57、10、12、13.33、14 | 两行三列 |

直接使用 main 的 `StimulusTable`、`gameStimulusTemplateForMode`、几何求解、资源缓存、elapsed RAF 相位、亮度映射及丢帧监控。没有新增闪烁引擎、发牌动画、游戏判题或识别答案。核心文件的版本哈希由测试保护。

- **灰度刺激块（solid）**：牌面矩形大小，正弦灰度调制。
- **外围闪烁（card）**：main 的灰色外围调制，牌面静止。
- **整体闪烁（card-face）**：整个牌面调制，无闪烁外围。

同数量下使用同一组实际几何、牌面内容、频率、相位、亮度基线 0.5、幅度 0.45、深度 1。所有中央注视点固定。全部目标同时闪烁，阶段提示给出指定位置、序号和频率；刺激完整持续 10 秒，提前识别不会结束试次。

外围与牌面实际调制面积不同，这是形式变量；数量之间频率、布局和面积也不同。因此不同数量的结果称为“配置效果比较”。首次刺激前锁定每种数量的实际几何；改变窗口尺寸后必须恢复该尺寸，或新建实验。

## 216 次主动试次与参考

三形式 ×（2 + 4 + 6 个注视目标）× 6 个重复组 = **216 次**。另有九种配置各一次 **10 秒静态参考**，共 225 个计划项。静态参考分布在第一组相应数量批次的开始，不作为六次独立重复。

六组各 36 次，拆为 6/12/18 次三个数量批次。六组的数量顺序依次为：

1. 2 → 4 → 6
2. 4 → 6 → 2
3. 6 → 2 → 4
4. 2 → 6 → 4
5. 6 → 4 → 2
6. 4 → 2 → 6

小批次内使用保存的 Mulberry32 种子随机排列形式与目标；保存实际顺序，续测不重新抽签。

每次准备 **2 秒**、刺激 **10 秒**、休息 **6 秒**。每个小批次结束或暂停后，至少休息 **60 秒**，手动继续。批后人工确认实际注视，勾选漏看、明显移动或不确定的试次；被排除项必须重做。记录批次不适评分 0–5。确认前不能进入下一批或正式分析。

前四组为开发/训练集；第五、六组为锁定测试集。静态参考仅供描述性比较。

## 首帧标记、停止与续测

每次在刺激开始前持久保存新 UUID，状态 `started`。Canvas 实际首帧触发开始标记，采用网关返回的全局样本索引对齐 worker。实际末帧统计和结束标记成功保存后才变为 `complete`。保存几何、调制区域、首末帧、样本索引、刷新率、跳帧、绘制耗时、导联、算法策略版本及人工注视确认。

断流、非有限 EEG、标记失败、隐藏窗口、刺激尺寸改变、设备维度改变或 main 判定的严重时序异常，会停止刺激并保留无效记录。暂停不自动补成成功。退出时的 `started` 记录载入后转为 `invalid`；重做使用新 UUID 关联原 `itemId`。已确认记录不可改写，历史不可删除，完成的计划项禁止再生成有效重复。

**同步精度**：当前仍为数据包到达时间估计，不是硬件同步。开始/结束标记保存 renderer callback delay、真实 RAF 时间和 EEG 新鲜度。分析排除明显延迟、短缺、断流或错误几何；不据此声称硬件相位锁定。

## 离线算法比较

停止采集后可分析开发集，或执行一次最终锁定评估。采集期间只运行 main FBCCA 与必要监控，其他算法只离线回放。

| 算法 | 预处理与实现 |
| --- | --- |
| CCA | 连续因果 2–45 Hz；与正余弦参考的标准典型相关，平方相关评分 |
| FBCCA-main | 直接执行生产 TS 实现：6–45/14–45 Hz 滤波器组、256 点热身、2.5 秒在线窗、0.25 秒 hop 和生产投票/拒识规则 |
| TRCA | 连续 2–45 Hz；独立重复间协方差与广义特征向量、单目标空间滤波模板相关 |
| eTRCA | 同一训练模板，所有目标的空间滤波器作集成投影相关 |

TRCA/eTRCA 核对了[作者 `src/trca.m` 与 `src/test_model.m`](https://github.com/mnakanishi/TRCA-SSVEP)。使用单个固定 2–45 Hz 频带，未复制作者完整滤波器组；加入固定 `trace(Q) * 1e-6 / 通道数` 的 ridge。验证独立的交叉试次协方差、广义特征向量残差、模板/集成投影及独立合成试次；核验失败明确不可用。滚动窗口训练模板按同一刺激起点、同一时间段切取，不混用相位位置。没有修改生产识别代码或采用原型校准模型。

开发集按完整组留一组交叉验证；每个“形式 × 数量”独立训练。2/3/4 秒窗、拒识 margin（0/0.05/0.1）、固定两次投票仅用开发集选择。一个试次的全部窗口始终在同一划分。前四组重新训练后，第五、六组一次性测试，第一次接受的错误选牌不能由后续窗口修正。

主指标是 **首 6 秒内逐试次选牌正确率**。FBCCA 的主指标始终复现生产 2.5 秒窗口流程；另列 2/3/4 秒固定窗的无拒识正确率。不要把辅助固定窗标签误认为生产窗口。首次正确决策时间单独列出，不修正首个决定。

最终评估写入 `evaluation-lock.json`，冻结开发集选定设置和源码、实验档案、会话元数据、标记、原始 EEG 内容哈希。锁定后不能改写采集档案；输出完成后只返回原有最终结果。无效试次不会因再次运行分析而变有效。

## 频谱与报告

整段 10 秒先连续滤波，再切完整 **1.5–9.5 秒**、早 **1.5–5.5 秒**、晚 **5.5–9.5 秒**。Hann PSD 在准确目标频率计算，分别输出基频、2 倍频和 3 倍频。超过或达到 45 Hz 的谐波记为缺失。四导联各自计算，主要区域固定为 **Oz/Pz 平均功率**，不先平均反相原始 EEG。

局部 SNR 使用目标两侧邻频平均功率，候选偏移 ±0.5/0.75/1/1.5/2 Hz；按窗口分辨率 `2 / 窗长` 排除所有同时呈现目标及其谐波附近污染点。至少四个有效邻频点才计算；不足时返回缺失与原因。方法参考 [MNE 频率标记分析](https://mne.tools/1.10/auto_tutorials/time-freq/50_ssvep.html)。不同窗长 SNR 不直接横比；早晚比较用相同四秒窗，仍为同一试次的配对变化。

输出：

- `development-` / `final-report.html`：逐试次与逐目标正确率、混淆矩阵、拒识、接受后正确率、首次正确决策时间、训练成本、算法耗时、质量与舒适度。
- `*-predictions.csv`：同一有效试次的四算法、窗口和策略结果。
- `*-spectra.csv`：所有呈现目标、三个谐波、四导联 PSD/SNR、Oz/Pz 功率、有效噪声频点及缺失原因。
- `*-excluded.csv`：无效、未确认、断流、标记/几何/时序错误记录。
- `*-summary.json`：全部指标、训练设置、前后窗变化、形式配对和静态参考描述性增强。

形式 SNR 与选牌正确率配对按完整组平均，使用精确符号翻转与 Holm 校正；早晚窗不当作额外重复。测试集只有两组，不以单次最高峰值选赢家。依据锁定测试逐试次正确率，结合拒识、SNR、稳定性和舒适度判断。未加入无注视闪烁条件，不能宣称拒识门槛已完成异步控制验证。

## 本地存储与复现

实验档案在 Electron `userData/stimulus-lab/<实验 UUID>/run.json`，原始会话在用户文档 `BrainGame/Sessions/<会话 UUID>/`。报告放在档案的 `analysis/`。两者都需本地备份，续测时保留原 UUID 和目录；源码 Git 不上传 EEG、报告、个人记录或测试产物。

也可从仓库根目录执行：

```powershell
python -m tools.stimulus_lab.analyze --run <run.json路径> --sessions <Sessions目录> --out <报告目录>
# 216 次全部完成、确认后，才使用 --final
```

## 验收

```powershell
npm run typecheck
npm run build
npm test
npm run test:lab-e2e
npm run test:lab-desktop
python -m unittest discover -s tools/ssvep_replay -p "test_*.py" -v
```

`test:lab-e2e` 构造完整 225 项模拟 EEG，验证 144/72 划分、四算法回放、报告导出及最终冻结；模拟结果不代表真实诱发效果。`test:lab-desktop` 使用独立回环模拟网关及隐藏的 1920×1080、DPR=1、60 fps 离屏合成器，检查真实 worker、10 秒首末帧标记和暂停/尺寸变化/标记失败/断流/隐藏等异常，不向人呈现闪烁。测试记录位于忽略的 `.smoke-user-data/`。

离屏资源测试包含额外读回开销，不能代替实验室无独显电脑的真实显示输出验证。正式采集前仍须手动做真实 EEG 小批次预检：核对四导联、实际帧质量、光电输出、注视状态和不适；预检合格后再开始完整协议。main 同步后必须更新基线版本并重跑亮度/相位、协议、回放及资源验证。
