# Table textures

Downloaded 2026-10-06. Both source assets are licensed CC0 1.0 and bundled
locally; the application makes no external texture requests at runtime.

## american-walnut-1k.jpg

- Asset: American Walnut Veneer, Poly Haven
- Source: https://polyhaven.com/a/american_walnut_veneer
- Download: https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/american_walnut_veneer/american_walnut_veneer_diff_1k.jpg
- License: https://polyhaven.com/license
- Unmodified 1K diffuse map. CSS applies a warm brown tint and fixed-size tiling.

## felt-fibers-1k.jpg

- Asset: Fabric 034 (felt), ambientCG
- Source: https://ambientcg.com/view?id=Fabric034
- Download: https://ambientcg.com/get?file=Fabric034_1K-JPG.zip
- Archive member: Fabric034_1K-JPG_Color.jpg
- License: https://docs.ambientcg.com/license/
- Unmodified 1K color map. Canvas multiplies it over a green base and repeats
