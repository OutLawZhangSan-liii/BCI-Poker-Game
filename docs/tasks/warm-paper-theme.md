# main 暖白主题改版

此文保留暖白版本的实现与验证历史。2026-10-21起默认呈现为 `crayon-paper-v1`，当前交付及现场验证缺口见 [手绘改版记录](handdrawn-paper-theme.md)；暖白版保留用于历史挑战恢复。

## 目标与当前快照

全应用采用暖白、墨黑、朱红点缀，保留神经元与定制瘦金字标。移除绿色桌布和木框，上方轻量工具区保留难度、局长、挑战、规则，底部仅保留开始游戏。按用户要求先将快照 `5d22da6` 提交并推送 main，再继续完成源码与离屏验证；快照之后的完善保留在本地工作区，尚未再次提交。

## 已完成

- 统一主题变量及 Canvas 暖白背景，复用背景与牌面缓存；原闪烁相位和亮度函数未修改。
- 墨色牌背、透明底神经元显示、浅色启动背景；翻牌与字标时间顺序不变。
- 游戏工具区、独立开始按钮、实际10/15轮进度圆点；挑战、排行榜、教学、设备和图表统一浅色适配。
- 呈现版本 `warm-paper-v1` 写入新挑战指纹及刺激开始标记。旧配置无版本按 `legacy-green-v1` 识别，仅允许在其他配置一致时续玩，保留旧背景；排名仍按完整指纹分组。
- 游戏刺激标记附响应式几何；排行榜默认选择本次记录的配置组，使用“暖白牌桌／旧版绿桌”说明。
- 修正教学配色变量的循环引用；Canvas及模拟时频图的尺寸观察回调通过RAF合并，避免修改画布尺寸引起ResizeObserver循环，窗口缩放的试次取消保护仍保留。
- 启动牌面下移以避开字标；翻牌2200ms、延迟550ms，以及字标1000ms、延迟2750ms保持原值。

## 初版标准绘制的性能证据与现场验证缺口

- 在同一离屏软件渲染窗口中遍历页面后，1920×1080六目标暖白测试的最大单帧绘制为约1.2ms，渲染进程工作集约215MiB、私有内存约71MiB；CPU约为一个逻辑核的10.8%。数值不包含Electron主进程或Python网关，亦不代表最低配置电脑。
- 暖白与旧版测试都出现离屏调度丢帧，并触发原有严重时序保护。报告明确给出 `display-timing-inconclusive-offscreen`；界面检查通过不能解释为60Hz实屏稳定性合格。软件测试均隔离，没有有效实验记录进入成绩或脑电分析。
- 上机后仍须在目标显示器1080p、60Hz、正常可见窗口下复核时序和整应用资源占用，再验证暖白背景的真实EEG诱发效果；本轮不采集真实EEG、不生成新版安装包。

## 牌面清晰度修正（2026-10-20）

- 原PNG约749×1044，模糊来自整个Canvas约105万像素、最多1倍绘制后再随高DPI放大。新游戏／教学默认 `sharp-v1`：最多2倍、约420万背板像素；超过90Hz保留原低预算。CSS牌面大小、位置、灰色外围比例、频率、相位与亮度函数不变。
- 牌面源图以高质量降采样绘制，缓存边界对齐背板整数像素，活动帧使用单位变换直接复制纹理；不是将低清图片人工放大。旧挑战（含暖白初版）使用原 `balanced-v1`，恢复时保留原指纹；新挑战记录 `rasterQuality`，分组区分画质配置。
- 定向13项测试通过：renderBudget、geometry、cardFaceBrightness及presentation；类型检查、构建通过。最新挑战报告 `.smoke-user-data/challenge-2026-10-20T13-23-12-651Z/challenge-smoke.json` 45项通过，含新增配置下的完整挑战及旧版续玩。
- 新绘制专项 `.smoke-user-data/presentation-2026-10-20T13-19-59-728Z/result.json` 使用 `--fixture-only`，8项检查及6组2/4/6目标布局通过：相同位置下背板分辨率提高，活动中画质锁定，360组同相位外围RGB一致，六张静止牌面内部从待机到闪烁的像素逐一一致，缩放取消保护有效。页面导航样式未修改，复用上节已通过的导航检查。
- 实测225%系统缩放下，1280×800软件窗口内牌桌背板从1232×533提高到2464×1066，视觉对照已检查。1920×1080 CSS软件窗口六目标高清绘制最大约2.3ms；渲染进程工作集约276MiB、私有约99MiB，CPU约一个逻辑核的20.3%。代价高于标准档位，保留像素预算；离屏调度仍丢帧，实屏60Hz结论仍未确认，不能以本项代替实机性能验收。
- 局部牌面对照、完整首页和两份报告保存于持久本地目录 `reports/card-sharpness-v1/`，不上传模拟记录。GitHub快照仍为 `5d22da6`，本次修改未再次提交或推送。
