# 神工 · 神游

Electron 桌面版 SSVEP 脑机接口扑克牌游戏，包含游戏牌桌、纸飞机、教学模式和顶栏设备操作。前端使用 React、TypeScript、Vite；Python 网关负责设备通信与本地会话录制。

## 纸飞机穿风廊

从顶部「纸飞机」进入。简单模式无风，困难模式有左右交替的侧风。局长可选 10 轮或不限轮数，默认不限；每经过一道风门计一轮。飞行通过 P3、P4、Oz、Pz 四个导联和左右 12 / 15 Hz 刺激块控制，需要先连接 EEG 并开始采集。飞行自动使用动态 1 / 2 秒识别窗。顶部中央提示准备状态、当前风门或暂停原因。右上角可打开「规则」，飞行中查看规则会暂停。所有风门使用相同尺寸的圆拱门框，沿路线左右错开，并随距离呈现近大远小的效果。抵达门口时，两翼完整穿过才计入通过数；碰到门框，这道门会标红，从外侧绕过则只计入遇到数。两个刺激块固定在飞机下方，十字中心分别位于航道宽度的 25% 和 75%，比飞机中心线低 26% 的画面高度。机翼可飞至航道宽度的 12.5% 和 87.5% 处。开始后飞行画面占满游戏窗口，暂停时可继续或结束，结束后恢复顶部导航。窗口失焦会自动暂停。

脑电模式可用方向键标记实际换向，用空格标记回看中央，键盘标记只用于统计。每局结束后自动保存到本机。结算显示穿过和遇到的风门数量，以及风门通过率（穿过数除以遇到数）。首道风门前结束时，通过率显示为「—」。本地记录另存机身在航道中央的停留时间，供分析飞行轨迹。

在线方向识别和换向时延的测量流程见[纸飞机在线控制预实验](docs/tasks/paper-plane-online-pilot.md)。

## Windows 安装版

安装程序为 `release/0.1.4/Shengong-Shenyou-Setup-0.1.4-x64.exe`。安装版已内置 Electron 和 Python 网关，无需另装 Node.js 或 Python。安装后从桌面“神工神游”启动；从 Windows“已安装的应用”或安装目录中的卸载程序卸载。卸载保留用户会话数据。

安装、卸载、构建和软件撰写资料见 [packaging/WINDOWS-RELEASE.md](packaging/WINDOWS-RELEASE.md)。

## 源码启动

需要 Node.js、npm 和可通过 `python` 命令运行的 Python 3.9 或更高版本。本机已验证 Node.js 24.18.1、Python 3.9.12；前端测试需要 Node.js 支持 `--experimental-strip-types`。

在项目根目录执行：

```powershell
npm ci
npm start
```

开发模式：

```powershell
npm run dev
```

应用自动启动 Python 网关。当前网关运行代码使用 Python 标准库；若使用虚拟环境，启动应用前先激活，使 `python` 指向该环境。

## 三关挑战与排行榜

游戏牌桌采用中式童趣粗蜡笔主题，上方左侧为难度、局长，右侧为“三关挑战”和规则；底部单独提供“开始游戏”。点击“三关挑战”后在小弹窗中填写学号和姓名，下一步查看简短规则，再开始简单、进阶、困难各10轮。弹窗底部提供与浅色面板融合的“排行榜”和“继续挑战”入口；浏览后返回仍保留已输入的身份。每次完整挑战独立上榜，同一人可有多条成绩；直接“开始游戏”为自由游戏，不进入挑战排名。教学在主导航中。设备操作集中在右上角。

课程字号随窗口的可用宽度和高度调整。拖动基频滑块可以对照各次谐波的位置。噪声和信噪比课程可独立调节模拟信号幅值、噪声标准差，观察同一标度上的功率谱和信噪比。实时识别示例支持播放和拖动时间，对比输入频率与最近 1 秒、4 秒的模拟判频。时频图只显示截至回放时刻已完成的 1 秒分析窗。信号观察和原理演示使用设备采集的 EEG。

游戏、教学、设备、排行榜和启动界面统一使用清爽白纸、藏蓝轮廓与强调及静态蜡笔笔触，保留神经元图标，品牌“神工神游”使用马善政矢量字标，顶部与启动界面统一。新记录写入呈现版本 `crayon-paper-v1`、牌组版本 `crayon-deck-v4`。新版数字牌与人物牌统一柔白纸面（#FFFEFC），中央注视点为带浅色描边的藏蓝十字；沿用无内框牌面、清晰纸边与单张牌背分层。旧挑战保留其已记录牌组的底色和圆形注视点。正式刺激沿用原亮度调制函数、频率与相位；续玩旧手绘／暖白／绿色挑战时保留已记录的背景、牌面、画质和配置指纹，新旧成绩按配置分组。图案与背景属于新的实验呈现条件，真实诱发效果需另行验证。

当前界面采用连续纸面排版：普通面板、导航和统计区域取消封闭边框，主要操作使用小面积蜡笔色块，教学与设备信息按标题和留白分组。排行榜采用居中圆角弹窗，按内容自适应高度，长列表在弹窗内滚动；左上“返回”退出榜单，刷新位于标题右侧，与系统窗口按钮分开；榜单类型、成绩列表和计算说明以留白及细横线分区，无外框。空榜显示提示，有成绩时再显示表头；身份与规则使用24px圆角的轻薄纸面浮层，弹窗遮罩同步调整右上角系统窗口按钮区的底色，关闭后恢复。难度和局长位于上移的独立两行设置区，向右展开时不覆盖牌桌；选择后停留约400毫秒，再以420毫秒动画收起，选中选项保留藏蓝色下划线。榜单与普通选择菜单使用藏蓝下划线。主导航和教学目录的选中样式见下方“教学与演示”。控件文字、箭头及状态提示统一使用藏蓝强调；输入聚焦只强调底线，键盘操作通过下划线定位，不再采用红色交互提示。新自由游戏与三关挑战使用全牌明暗闪烁，移除灰色外围，候选牌采用疏朗布局，牌面与参考牌较上一版再放大5%并整体下移，小窗口自适应安排牌堆；准备和观察时显示原始牌面，闪烁时沿用原正弦频率／相位，亮峰保留原图，暗谷约为5%显示RGB。中央十字保持固定，参考牌不闪烁。旧挑战继续其已记录的外围刺激与尺寸，新旧成绩分组。

新游戏及教学使用1020×1425手绘牌图与 `sharp-v1` 高清绘制，按屏幕DPI提高绘制分辨率，最高2倍、约420万背景像素；缓存按背板像素直接复制，避免再次缩放模糊。超过90Hz的显示模式沿用约105万像素预算。旧挑战保留原牌图与已记录的画质，缺少画质字段的历史记录沿用 `balanced-v1`；新挑战的清晰度档位写入配置与刺激标记，按配置分组。

手绘牌组包含52张标准牌、两张大小王和统一牌背。A（1）—10的四种花色采用用户提供的网页样稿，40张牌已静态导出，见 [点数牌说明与重建方法](artwork/web-pips-v2/README.md)；J／Q／K及牌背基于 [首版手绘素材](artwork/crayon-v1/README.md)。当前v4从原模板移除牌面内框、统一底纸并重新导出，重建命令为 `npm run build:cards:uniform`；v1、v2、v3素材继续供历史挑战使用。图片按当前牌局加载，解码缓存最多12张、64MiB，当前资源优先保留；纸纹与装饰预先缓存，刺激期间不生成手绘纹理。

游戏现在每轮只进行一次有效识别：正确、错误或刺激结束后仍未确定／拒识，均进入下一轮。拒识不得分并中断连胜，不再自动重试同一手牌；设备断流、显示异常等取消的尝试标为无效，可以恢复当前轮。

综合榜依次比较正确率、平均识别用时、单关最长连胜；另有准确榜、速度榜和连胜榜。速度榜要求正确率至少70%，比较正确轮次的平均用时。排序用完整精度，同分并列排名。当前无拒识重试，首次正确率与最终正确率相同；错误和拒识都计入正确率分母。

用时基于应用首个刺激绘制帧与决策／超时的单调时钟时间差，包含分析等待，排除准备与休息；不是硬件或光电同步测量。界面可展开“成绩如何计算”查看口径。每关最长连胜独立计算，挑战取三关最大值。

成绩保存于用户文档目录 `BrainGame/Challenges/`，按挑战独立保存，包含完整身份、手牌、尝试、EEG 会话关联和配置版本；排行榜只显示学号尾四位。不同规则／识别／刺激配置分组。退出或重启后可在三关挑战弹窗中点击“继续挑战”恢复，已完成轮次保留，异常中的尝试作废；关间至少休息30秒。保存失败会暂停并提供“重试保存”，请先完成保存再关闭窗口。

源码入口与验收说明见 [三关挑战交接记录](docs/tasks/three-stage-challenge.md)、[手绘改版交接记录](docs/tasks/handdrawn-paper-theme.md)；此前暖白改版见 [历史主题记录](docs/tasks/warm-paper-theme.md)。这些本地成绩不会上传 GitHub，也不会用历史 EEG 会话自动补生成排行榜成绩。

真实采集前先打开厂商采集软件及数据服务。点击右上角「设备」展开设备面板。网关状态显示在面板内，未启动可开启，启动失败可重试。网关就绪后依次点击「连接设备」「开始采集」。面板底部的「设备与诊断」直接打开设备属性、实时链路及日志与会话信息，也可从该页打开本地会话目录。默认设备数据服务为 `127.0.0.1:7110`，配置见 `device_gateway/config.py`。没有采集设备时可查看界面与教学内容，正式脑控选牌需要真实 EEG。

### 游戏识别方案

新开的自由游戏和三关挑战自动使用 **Butterworth** 识别。续玩挑战使用记录中的识别与呈现配置。

游戏识别使用P3/P4/Oz/Pz、6—45Hz与14—45Hz持续Butterworth双带滤波、原始加权CCA评分及连续两票；占比门槛0.25、差距门槛0.08。它仍属于滤波器组CCA方案，Butterworth是滤波方式。教学使用原有识别实现。

新牌桌将阶段提示移到底部并加大，提示、倒计时与识别结果统一使用界面楷体。三类结果共用字号与排版：正确为绿色勾，错误为红色叉，未确定为灰蓝问号；分别配合短入场、轻摆和淡入效果，标记以手绘笔画出现。正确选中描边保持绿色，错误选中描边使用红色；开启系统“减少动态效果”时关闭文字和标记动画。三种难度扩大候选牌并增加牌间净距，为提示预留独立空间。

五名被试旧数据的360次决策已与独立离线方案逐次核对一致；这属于探索性回放核验，不能替代当前新版全牌刺激的真实EEG验证。实现、参数及验证证据见 [Butterworth试用交接记录](docs/tasks/butterworth-trial.md)。
## 教学与演示

课程页固定标题、核心概念、观察／练习区及底部导航的位置，八门课切换时保持对齐。宽屏且高度充足时，练习排在观察内容下方，课程目录随可用高度排开。较矮的宽窗口并排显示观察和练习，小窗口通过页签切换。课程目录和讲义采用开放式纸面布局，标题使用淡蓝墨刷。核心概念以较小字号排在课程标题右侧。“进一步理解”在窗口中央展示原理和实例，可点击“关闭”或按 Esc 回到课程。

主导航以墨色深浅、字重和轻微放大标出当前页。三个教学子页以文字左上、右下的墨角标出当前页。课程目录在当前课程左侧显示书签，右侧的勾表示已经完成。小窗口的课程下拉菜单沿用书签。减少动态偏好下关闭切换过渡，正式刺激或训练准备期间取消内容入场动画。

真实观察、原理演示与模拟分析的参数在按钮右侧横向展开，用竖线分隔数据项；较窄区域可自动换成短行，保留参数和告警。原理演示精简重复说明，功率谱下方新增时频图，共用通道选择和Worker输出的同一PSD／样本边界。时频图展示约30秒的滑动窗口功率历史，横轴为窗口中心时刻，色标为相对1μV²/Hz的dB值；不新增FFT或分类路径。换通道、试次、采样率、滤波条件以及断流／无效窗口会清空历史，无设备时保持空图。

实现与验证见[教学改版交接记录](docs/tasks/teaching-refresh.md)。

## 后续刺激参数与实验

- 原理演示支持在界面调整目标频率、目标数量和观察目标；实验开始前确定参数，试次中保持配置不变。
- 几何尺寸与相位逻辑分别位于 `renderer/src/bci/stimulus/geometry.ts`、`phase.ts`；绘制与亮度调制见 `renderer/src/components/StimulusTable.tsx`。
- 注视对照协议、条件随机化和数据新鲜度策略见 `renderer/src/bci/stimulus/comparison.ts`；启动与标记写入见 `renderer/src/main.tsx`。
- 当前短版对照比较外围闪烁、牌面闪烁、纯色块，以及固定/同步闪烁注视点；保存实际刺激配置与几何。历史实验协议保留，分析时按协议区分。
- 当前识别使用 P3/P4/Oz/Pz；个人校准未接入选牌。参数有效性需结合独立注视试次和显示输出测量确认。
- 实际注视需人工确认。当前标记对齐基于数据包到达时间估计，不能据此声称硬件同步或相位锁定。

详细设备说明见 [device_gateway/README.md](device_gateway/README.md)，实验分析说明见 [tools/ssvep_replay/README.md](tools/ssvep_replay/README.md)。

```powershell

```

`npm test` 包含前端刺激/识别测试，以及 Python 网关测试；网关集成测试使用本地模拟服务器，需要允许回环套接字连接。

主题兼容与界面专项检查：

```powershell
npm run test:presentation
npm run test:presentation-ui
# 已构建后，仅检查弹窗／窗口按钮颜色与圆角
node tools/window-appearance-smoke.cjs
```

挑战专项测试与桌面端模拟验收：

```powershell
npm run test:challenge
npm run test:challenge-ui
```

## 本地数据

应用会话保存于用户文档目录的 `BrainGame/Sessions/`，包含原始 EEG、刺激标记和分类决策。原始会话、采集文件、个人实验笔记、报告、缓存、依赖与构建产物由 `.gitignore` 排除，源码仓库不承担实验数据备份。

已有 Git 历史中的文件不会因新增忽略规则自动移除；发布前需要同时检查提交内容与历史。实验数据应单独保存在可追溯的本地目录。

## 扑克牌整体闪烁亮度

整体牌面使用 `black-overlay-linear-rgb-v2`，默认正弦输入映射为原图 RGB 的 5%–100%；亮峰保留原图，暗谷覆盖 95% 黑色。此范围为显示颜色值，不是光电实测亮度。频率、相位与闪烁时序保持不变，外围闪烁及纯色块映射不变。实验标记记录新版本与映射，旧版 v1 数据应分开比较。
